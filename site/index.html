Questions

What does it cost?

Klipolo is free while in beta, and it comes with free AI credit to try the AI features. For more, add your own Meta API key, which Meta bills, or an access code. Klipolo shows the price before each analysis, and the clip card shows it before following a speaker. Recording, editing and export use no credit.

Does it work offline?

Recording, editing and export work offline. Analysis, chat, pictures and following a speaker need the internet.

What does it send, and where?

To Meta’s model API: the audio, low-resolution copies of the video, your chat messages with the project’s name, transcript, scene log and file names, and what you ask Muse Image to draw. To Klipolo’s server: the audio and transcript, to time each word, and your requests to Meta when you use the free credit or an access code. The server keeps no audio, video or text, only each call’s usage and cost, and each Mac’s word timing minutes for the day. More on the privacy page.

Which languages does it understand?

Klipolo hears the language on its own: English, Hindi and the other languages Meta’s transcriber knows. Captions draw Latin, Devanagari and other Indian scripts, Arabic, Hebrew, Thai, Chinese, Japanese and Korean. You can fix any word by hand.

Can other apps edit with Klipolo?

Yes. Klipolo is an MCP server. Turn on Let other apps edit with Klipolo in Settings, and AI agents and other MCP apps can edit the open project with chat’s tools. Cuts still wait for your Apply.

Will it cut anything without asking?

No. Anything that removes footage comes back as a proposal, with the parts to cut in red. You approve it first. Undo is one step.

Which Macs does it run on?

Apple Silicon and Intel Macs running macOS 15 or later. Windows and Linux versions are coming soon.

Is Klipolo made by Meta?

No. Klipolo is built on Meta’s models. Meta did not make it and does not endorse it.
